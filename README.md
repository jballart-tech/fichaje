# Tarjeta de fichaje

App web instalable para registrar la jornada laboral desde el iPhone.

- Fichaje de entrada, pausa, reanudación y salida con la hora del servidor.
- Ubicación GPS opcional en cada fichaje.
- Correcciones y anulaciones con motivo, sin borrar el original.
- Resumen diario, semanal y mensual con horas extra sobre una jornada de 40 h.
- Exportación mensual a Excel y copia de seguridad en iCloud Drive.

Los fichajes se guardan solo en el iPhone. Este repositorio contiene el código, nunca los datos.

## Instalar en el iPhone

1. Abre la web de GitHub Pages en Safari.
2. Toca Compartir y luego «Añadir a la pantalla de inicio».
3. Ficha siempre desde el icono.

## Publicar cambios

Al cambiar archivos, sube la constante `VERSION` de `sw.js` para que la app instalada descargue la versión nueva.
